# repo's requirements.txt that `discovery.node` actually imports.

# the heartbeat's load numbers. It never touches web3, fastapi, pandas or
# matplotlib, so those stay out of the image: a smaller image builds faster and
# has less that can drift from the host environment.
#
# Every line here must appear verbatim in the repo's requirements.txt.
# tests/test_swarm.py::test_node_requirements_match_repo_requirements enforces
# that, so the container can never silently run a different pin than the host.
